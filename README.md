## 4. Quickstart Guide

### Prerequisites
- Node.js `v20+` or `v22+`
- npm `v10+`

### Installation
```bash
# Clone or navigate to the repository
cd c:\hash.devs

# Install project dependencies
npm install

# Install Playwright browser binaries
npx playwright install chromium
```

### Development
```bash
# Start local Vite development server (default: http://localhost:5173)
npm run dev
```

### Production Build
```bash
# Typecheck and build optimized bundle for production
npm run build

# Preview production build locally
npm run preview
```

### End-to-End Testing (Playwright)
```bash
# Run headless tests across desktop and mobile viewports
npm run test:e2e

# Run tests in interactive UI mode
npm run test:e2e:ui

# View latest HTML test report
npm run test:e2e:report
```
